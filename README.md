# GenerativeAIhw1

This repository contains my Homework 1 submission for the Generative AI course. It demonstrates using a coding assistant (Claude Code) to create a draft file, making manual edits, and tracking work with Git and GitHub.

## Git Workflow

The Git commands I used throughout this assignment:

- `git clone` to clone the repository locally
- `git add .` to stage changes
- `git commit -m "message"` to commit changes
- `git push` to push commits to GitHub
